# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting or open a private security advisory in this
repository. Do not include credentials, private Bitbucket URLs, access tokens, or production page
content in a public issue.

The extension intentionally has no remote backend and requests host access only for the site the
user connects. Changes that broaden permissions should be treated as security-sensitive.
