# Privacy

BetterStash does not collect, transmit, sell, or share personal data.

The extension processes the currently rendered Bitbucket Server or Data Center dashboard in the
browser to classify pull requests. It makes no REST API calls and has no analytics, advertising,
or external services.

Settings—including the configured site origin, display name, and optional teammate names—are
stored in `chrome.storage.local` on the user's device. They are not synchronized by this
extension or sent to the maintainer.

Host access is optional. The browser requests access only to the origin entered by the user, and that
permission can be removed at any time with **Disconnect** in the extension settings or through
your browser's extension controls.
